# ✊🖐✌️ Rock Paper Scissors  

## 👋 About the Project  
Hey there! 👋 This is a **simple Rock Paper Scissors game** made using **HTML, CSS, and JavaScript**.  
It’s a fun way to practice **JS logic**, **event handling**, and **DOM manipulation** while keeping the design simple and colorful 🎨  

## ⚙️ Features  
- 🎮 Interactive gameplay between **You** and **Computer**  
- 🧠 Random computer moves using JavaScript logic  
- 🏆 Score tracking for both players  
- 🔁 “Play your move” button to start each round  
- 💻 Clean and responsive layout  

## 🧩 Tech Stack  
| 💡 Technology | 🔍 Purpose |
|----------------|------------|
| 🌐 **HTML** | Structure of the game |
| 🎨 **CSS** | Styling and layout |
| ⚡ **JavaScript** | Game logic and interactivity |
